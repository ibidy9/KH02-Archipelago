# Kingdom Hearts 0.2 — Steam Public Beta

First public-testing release of Kingdom Hearts 0.2 Archipelago for Windows/Steam.

Randomize abilities, progressive magic, world access, wardrobe, and other rewards. Choose Demon Tide or Zodiac Phantom as your goal, customize your starting loadout, and optionally enable randomized Mickey, traps, and DeathLink. Includes seed-specific saves and PopTracker support.

## Install

Download **kh02.apworld** below and install it through Archipelago Launcher. Restart the launcher, create your YAML, and open **KH 0.2 Client** to connect to your room.

**Open Steam → connect the KH client → wait for “AP is prepared” → launch 2.8 and select 0.2.**

The APWorld includes the client and required mod. No separate mod installation is needed. Download **kh02-poptracker-0.4.11.zip** if you want the tracker.

See the repository README or **START-HERE.txt** for complete instructions, save handling, and difficulty commands. Do not use GitHub's automatic Source code downloads for installation.

## Testing notes

The seeded playthrough reached its goal. Follow-up fixes for Main Road magic/Shotlock, HP preservation, completed WW mirrors, reward popups, and client shutdown have passed their live checks.

This is a public beta. Please report bugs through the repository's Issues page. Windows/Steam only; Epic Games Store support is deferred. Mickey may navigate awkwardly outside Depths, and very long popup text may extend beyond its background.
